# input/

Material for the new project: design exports (HTML canvases, screenshots), notes and specs (markdown, PDF, text), API docs or sample data for the systems the UI will show, screenshots of tools you like or dislike.

You can drop it here before running `/start-project`, or just tell the agent where it is, paste it into the chat, or give links. Step 1 collects everything here, renders HTML exports to PNG, and extracts the intent: what to keep, what to drop. Nothing in it is treated as final.

Everything in this folder except this README is gitignored. Delete it whenever you like.
